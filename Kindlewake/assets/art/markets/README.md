# Regional trade-goods icon atlas

- File: `trade_goods_atlas.svg`
- Canvas: 384 × 128 SVG.
- Layout: 6 columns × 2 rows.
- Cell size: 64 × 64 logical pixels.
- Contents: 12 original KindleWake trade-goods symbols.
- Runtime: `scripts/ui/trade_goods_icon_atlas.gd`, displayed in the regional exchange rows.
- Mapping: stable `trade_goods.json` IDs, never display-name substring matching.

The art uses the existing deep-ink, parchment, brass and muted coastal palette. Each symbol remains legible when rendered at 44 × 44 UI pixels.

No raster images, external fonts, linked files, scripts, filters, masks or third-party source material are embedded.
